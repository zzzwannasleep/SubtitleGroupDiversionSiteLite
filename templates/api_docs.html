📚 API 文档

通过 API 对接第三方应用，实现自动化种子管理和发布。

🔌 基础信息

🔐 认证方式

所有 API 请求都需要认证。支持以下方式传递 API Key：

  1. Header（推荐）： X-API-Key: your-api-key
  2. Query参数： ?api_key=your-api-key
  3. JSON Body： {"api_key": "your-api-key"}（仅POST请求）
💡 提示： 在 API Key 管理页面 创建你的 API Key。
只有 发布员 或 管理员 才能通过 API 上传种子。

Base URL： {{ base_url }}/api/v1

响应格式： 所有响应均为 JSON

RSS地址： {{ base_url }}/rss.xml

📊 获取站点统计

GET /stats

描述：获取站点统计信息（无需认证）

请求示例：

curl "{{ base_url }}/api/v1/stats"

响应示例：

{
  "success": true,
  "data": {
    "total_torrents": 150,
    "total_users": 25,
    "total_size": 10737418240,
    "total_size_human": "10.00 GB",
    "recent_torrents_24h": 5,
    "site_name": "RSS种子站点",
    "rss_url": "{{ base_url }}/rss.xml"
  }
}

📋 获取种子列表

GET /torrents

描述：获取种子列表（需要认证）

查询参数：

参数 类型 必填 说明
page integer 否 页码，默认1
per_page integer 否 每页数量，默认20，最大100
category string 否 分类过滤
search string 否 搜索关键词（标题和描述）

请求示例：

curl -H "X-API-Key: your-api-key" \
  "{{ base_url }}/api/v1/torrents?page=1&per_page=20&category=movie"

响应示例：

{
  "success": true,
  "data": {
    "torrents": [
      {
        "id": "uuid-string",
        "title": "电影名称",
        "description": "电影描述",
        "category": "movie",
        "file_size": 2147483648,
        "file_size_human": "2048.00 MB",
        "created_at": "2024-01-15T10:30:00",
        "publisher_name": "username",
        "download_url": "{{ base_url }}/download/uuid-string"
      }
    ],
    "pagination": {
      "page": 1,
      "per_page": 20,
      "total": 150,
      "total_pages": 8
    }
  }
}

🔍 获取单个种子详情

GET /torrents/:id

描述：获取单个种子详细信息（需要认证）

路径参数：

参数 类型 必填 说明
id string 是 种子ID

请求示例：

curl -H "X-API-Key: your-api-key" \
  "{{ base_url }}/api/v1/torrents/uuid-string"

📤 上传种子

POST /torrents

描述：上传种子文件（需要发布员/管理员权限）

⚠️ 注意： 只有角色为 publisher 或 admin 的用户才能上传。

请求格式： multipart/form-data

表单参数：

参数 类型 必填 说明
torrent file 是 .torrent 文件
title string 是 种子标题
description string 否 种子描述
category string 否 分类（默认general）

请求示例：

curl -X POST \
  -H "X-API-Key: your-api-key" \
  -F "torrent=@/path/to/file.torrent" \
  -F "title=电影标题" \
  -F "description=电影描述" \
  -F "category=movie" \
  "{{ base_url }}/api/v1/torrents"

响应示例（成功）：

{
  "success": true,
  "data": {
    "id": "uuid-string",
    "title": "电影标题",
    "download_url": "{{ base_url }}/download/uuid-string",
    "message": "Torrent uploaded successfully"
  }
}

❌ 错误码

状态码 说明
200 请求成功
400 请求参数错误
401 未认证或 API Key 无效
403 权限不足（需要发布员/管理员）
404 资源不存在
500 服务器内部错误

💡 对接示例

Python 示例

import requests

BASE_URL = "{{ base_url }}"
API_KEY = "your-api-key"

headers = {
    "X-API-Key": API_KEY
}

# 1. 获取统计信息
response = requests.get(f"{BASE_URL}/api/v1/stats")
print(response.json())

# 2. 获取种子列表
response = requests.get(
    f"{BASE_URL}/api/v1/torrents",
    headers=headers,
    params={"page": 1, "per_page": 20}
)
print(response.json())

# 3. 上传种子
with open("movie.torrent", "rb") as f:
    files = {"torrent": f}
    data = {
        "title": "电影名称",
        "description": "电影描述",
        "category": "movie"
    }
    response = requests.post(
        f"{BASE_URL}/api/v1/torrents",
        headers=headers,
        files=files,
        data=data
    )
    print(response.json())

JavaScript (Node.js) 示例

const axios = require('axios');
const FormData = require('form-data');
const fs = require('fs');

const BASE_URL = '{{ base_url }}';
const API_KEY = 'your-api-key';

const headers = {
    'X-API-Key': API_KEY
};

// 获取种子列表
axios.get(`${BASE_URL}/api/v1/torrents`, { headers })
    .then(response => console.log(response.data))
    .catch(error => console.error(error.response.data));

// 上传种子
const form = new FormData();
form.append('torrent', fs.createReadStream('movie.torrent'));
form.append('title', '电影名称');
form.append('category', 'movie');

axios.post(`${BASE_URL}/api/v1/torrents`, form, {
    headers: {
        ...headers,
        ...form.getHeaders()
    }
})
.then(response => console.log(response.data))
.catch(error => console.error(error.response.data));

🚀 对接流程

  1. 注册账号： 在站点注册一个账号
  2. 获取权限： 联系管理员将你的账号设置为 发布员
  3. 创建 API Key： 访问 API Key 管理 页面创建 Key
  4. 保存 Key： ⚠️ 立即复制保存，这是唯一一次完整显示！
  5. 配置应用： 将 API Key 填入第三方应用
  6. 开始对接： 使用上述 API 端点进行开发
💡 提示： 如果你在开发第三方应用（如自动发布工具、RSS订阅器等）， 建议使用 /api/v1/stats 接口测试连接，此接口无需认证。
