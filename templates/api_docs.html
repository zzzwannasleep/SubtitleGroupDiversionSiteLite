📚 API 文档

简单的 RSS 种子站点 API，上传种子，通过 RSS 订阅下载。

🔌 基础信息

🔐 认证方式

API Key 传递方式：

  1. Header（推荐）： X-API-Key: your-api-key
  2. Query参数： ?api_key=your-api-key
在 API Key 管理 页面创建 Key。
只有 发布员 才能通过 API 上传。

Base URL： {{ base_url }}/api/v1

RSS地址： {{ base_url }}/rss.xml

📊 获取站点统计

GET /stats

描述：获取站点统计（无需认证）

请求：

curl "{{ base_url }}/api/v1/stats"

响应：

{
  "success": true,
  "data": {
    "total_torrents": 150,
    "total_users": 25,
    "total_size_human": "10.00 GB",
    "recent_torrents_24h": 5,
    "rss_url": "{{ base_url }}/rss.xml"
  }
}

📋 获取种子列表

GET /torrents

描述：获取种子列表（需要认证）

参数：

参数类型必填说明
pageinteger否页码，默认1
per_pageinteger否每页数量，默认20，最大100
searchstring否搜索标题

请求：

curl -H "X-API-Key: your-api-key" \
  "{{ base_url }}/api/v1/torrents?page=1&per_page=20"

🔍 获取单个种子

GET /torrents/:id

描述：获取单个种子详情（需要认证）

路径参数：

参数类型必填说明
idstring是种子ID

请求：

curl -H "X-API-Key: your-api-key" \
  "{{ base_url }}/api/v1/torrents/uuid-string"

📤 上传种子

POST /torrents

描述：上传种子（需要发布员权限）

⚠️ 注意： 只有 publisher 或 admin 才能上传。

格式： multipart/form-data

参数：

参数类型必填说明
torrentfile是.torrent 文件
titlestring是种子标题

请求：

curl -X POST \
  -H "X-API-Key: your-api-key" \
  -F "torrent=@/path/to/file.torrent" \
  -F "title=电影标题" \
  "{{ base_url }}/api/v1/torrents"

响应：

{
  "success": true,
  "data": {
    "id": "uuid-string",
    "title": "电影标题",
    "download_url": "{{ base_url }}/download/uuid-string",
    "message": "Torrent uploaded successfully"
  }
}

👤 获取当前用户

GET /user

描述：获取当前用户信息（需要认证）

请求：

curl -H "X-API-Key: your-api-key" \
  "{{ base_url }}/api/v1/user"

响应：

{
  "success": true,
  "data": {
    "id": "user-uuid",
    "username": "yourname",
    "role": "publisher"
  }
}

❌ 错误码

状态码说明
200成功
400参数错误
401未认证或 Key 无效
403权限不足（需要发布员）
404资源不存在
500服务器错误

💡 代码示例

Python

import requests

BASE_URL = "{{ base_url }}"
API_KEY = "sgd_your_api_key"

headers = {"X-API-Key": API_KEY}

# 获取统计
r = requests.get(f"{BASE_URL}/api/v1/stats")
print(r.json())

# 获取种子列表
r = requests.get(f"{BASE_URL}/api/v1/torrents", headers=headers)
print(r.json())

# 上传种子
with open("movie.torrent", "rb") as f:
    files = {"torrent": f}
    data = {"title": "电影名称"}
    r = requests.post(
        f"{BASE_URL}/api/v1/torrents",
        headers=headers,
        files=files,
        data=data
    )
    print(r.json())

cURL

  -F "title=电影名称" \
